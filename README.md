# Thailand PromptPay

A WordPress plugin for integrating PromptPay payment system in Thailand.

## Description

Thailand PromptPay is a WordPress plugin that allows you to easily integrate PromptPay payment system into your WordPress website. It provides a simple and secure way to accept payments through Thailand's PromptPay system.

## Features

- Easy integration with WordPress
- Customizable payment form
- Support for multiple currencies
- Secure payment processing
- Mobile-friendly design
- Admin settings panel

## Installation

1. Upload the `thailand-promptpay` folder to the `/wp-content/plugins/` directory
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Go to the Thailand PromptPay settings page to configure your payment settings

## Usage

1. Add the shortcode `[thailand_promptpay]` to any post or page where you want to display the payment form
2. Configure your payment settings in the WordPress admin panel under "Thailand PromptPay"
3. Customize the appearance using the provided CSS classes

## Requirements

- WordPress 5.0 or higher
- PHP 7.2 or higher
- MySQL 5.6 or higher
