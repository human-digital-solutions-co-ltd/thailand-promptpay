# Thailand PromptPay

A WordPress plugin for integrating PromptPay payment system in Thailand.

## Description

Thailand PromptPay is a WordPress plugin that allows you to easily integrate PromptPay payment system into your WordPress website. It provides a simple and secure way to accept payments through Thailand's PromptPay system, supporting both personal (phone number) and business (tax ID) accounts.

## Features

- Easy integration with WordPress
- Support for both personal and business PromptPay accounts
  - Phone number-based payments
  - Tax ID-based payments for businesses
- Customizable payment form
- Secure payment processing
- Mobile-friendly design
- Admin settings panel
- WooCommerce HPOS (High-Performance Order Storage) compatible
- Block Checkout compatible

## Installation

1. Upload the `thailand-promptpay` folder to the `/wp-content/plugins/` directory
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Go to WooCommerce > Settings > Payments > Thailand PromptPay to configure your payment settings

## Configuration

1. Enable the payment gateway
2. Set your payment method title and description
3. Choose your PromptPay ID type:
   - Phone Number: For personal accounts
   - Tax ID: For business accounts
4. Enter your PromptPay ID (phone number or tax ID)
5. Customize the payment instructions

## Requirements

- WordPress 6.4 or higher
- PHP 8.0 or higher
- WooCommerce 9.0.0 or higher
- MySQL 5.6 or higher
